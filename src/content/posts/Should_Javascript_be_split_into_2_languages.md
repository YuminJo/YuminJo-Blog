# JavaScript 분할 제안이란? / JavaScript分割提案とは?

<details>
<summary>Google 엔지니어가 공식 표준화 위원회에 JavaScript를 두 개의 언어로 분할하는 제안</summary>

> **한글:** Google 엔지니어가 공식 표준화 위원회에 JavaScript를 두 개의 언어로 분할하는 제안을 발표  
> 엔진에서 구현되는 언어를 "JS0"라고 하고, 도구에서 구현되는 언어를 "JSSugar"로 분할  
> 이렇게 분할하면 결국 도구에 대한 의존성이 강해짐  
> **日本語:** Googleエンジニアが公式標準化委員会にJavaScriptを2つの言語に分割する提案を発表  
> エンジンで実装される言語を「JS0」、ツールで実装される言語を「JSSugar」に分割  
> こう分割すると、結局ツールへの依存性が強くなる
</details>
