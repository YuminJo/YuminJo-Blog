# JSON 란? / JSON は？

## JSON 개념 / JSONの概念

<details>
<summary>JsonはJavascriptオブジェクト文法で構造化されたデータ交換形式</summary>

> **한글:** JSON은 Javascript 객체 문법으로 구조화된 데이터 교환 형식  
> **日本語:** 複数のコンピュータプログラム間でデータをやり取りするため、JavaScriptオブジェクト構文で構造化された形式
</details>
